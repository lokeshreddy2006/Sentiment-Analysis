# Dataset

This folder contains the dataset used for the sentiment analysis project.

## Dataset Information

The project uses the **IMDb Movie Reviews Dataset**, containing 50,000 movie reviews classified into two sentiment categories:

* Positive — 25,000 reviews
* Negative — 25,000 reviews

The dataset is balanced, with each sentiment class representing 50% of the total reviews.

## Dataset File

The original dataset file is named:

`IMDB Dataset.csv`

The dataset is not included in this GitHub repository because the file size exceeds GitHub's recommended file size limit.

## How to Use

Download the IMDb Movie Reviews dataset and place the CSV file inside this `data` folder with the following filename:

`IMDB Dataset.csv`

The notebook can then be executed using the dataset.

## Note

The dataset is used for educational and machine learning experimentation purposes.
